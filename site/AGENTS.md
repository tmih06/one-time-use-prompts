# Fumadocs

This site is a static [Astro](https://astro.build) build that renders [Fumadocs](https://fumadocs.dev) React components at build time. No React ships to the browser except the lazy search dialog; page interactivity lives in `src/scripts/site.ts`. The APIs and conventions of Fumadocs may differ from your training data, so check its docs for the task at hand:

- Writing pages: https://fumadocs.dev/docs/markdown.md
- Organizing pages and folders: https://fumadocs.dev/docs/page-conventions.md
- Customizing the UI: https://fumadocs.dev/docs/guides/customize-ui.md
- Changing the theme and colors: https://fumadocs.dev/docs/ui/theme.md
- Upgrading Fumadocs: https://fumadocs.dev/docs/upgrade.md
- Other tasks: https://fumadocs.dev/llms.txt lists every docs page.
